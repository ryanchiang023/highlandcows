# Highland Cows

This project is an informational website about Highland cows, exploring their history, physical characteristics, and interesting facts.

The goal of this website is to introduce visitors to Highland cattle and provide information about what makes this breed unique.

## Topics Covered

- History and background of Highland cattle
- Physical characteristics and appearance
- Interesting facts about the breed

## Languages Used

- HTML
- CSS
